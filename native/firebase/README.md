# Firebase config

`google-services.json` (Android) and `GoogleService-Info.plist` (iOS) for the
Firebase project `ediagd-8c0a5`, both bound to bundle id `ai.ediagd.app`.

They live here rather than inside `ios/` and `android/` because those two
directories are generated by `npx cap add` and are not the source of truth —
`npm run native:sync` copies these into place after every regeneration.

## Are these secret?

No, and yes. They carry no server credential: a Firebase mobile config is
designed to be embedded in a shipped binary, and anyone with the app has it.
They do identify the project, and the Android one carries an API key that should
be restricted in the Google Cloud console to the app's SHA-256 fingerprints.

They are safe to commit. Ryan's call whether to — if he'd rather not, add
`native/firebase/` to .gitignore and hand them over out of band, because the
build needs them.
