# Firebase config

**The two files point at two different Firebase projects. That is deliberate,
and each one is named below — do not assume they match.**

| file | platform | Firebase project | project number |
|---|---|---|---|
| `google-services.json` | Android | **`ediagd-3fcb5`** | 347930705588 |
| `GoogleService-Info.plist` | iOS | **`ediagd-8c0a5`** | 983447476679 |

Both are bound to bundle id `ai.ediagd.app`.

Android moved to `ediagd-3fcb5` on 14 November because that project lives under
the Pear Tree account that owns the Play Console, and Play wants the app's
Firebase project in the same account. iOS was left on `ediagd-8c0a5` — it is a
separate submission with nothing waiting on it, and moving it would invalidate
the APNs key setup described below.

**The consequence to remember:** anything server-side that names a Firebase
project has to pick per platform rather than once. The FCM sender sketched in
the Android release report lists a single `FIREBASE_PROJECT_ID` env var; for
Android that value is `ediagd-3fcb5`, and an APNs/FCM-for-iOS path would need
`ediagd-8c0a5`. One variable cannot serve both.

They live here rather than inside `ios/` and `android/` because those two
directories are generated by `npx cap add` and are not the source of truth —
`npm run native:sync` copies these into place after every regeneration.

## Are these secret?

No, and yes. They carry no server credential: a Firebase mobile config is
designed to be embedded in a shipped binary, and anyone with the app has it.
They do identify the project, and the Android one carries an API key that should
be restricted in the Google Cloud console to the app's SHA-256 fingerprints.
**That restriction is per project**, so it has to be applied to the new
`ediagd-3fcb5` key — the old project's key no longer ships in the Android app,
and restricting it would protect nothing.

They are safe to commit. Ryan's call whether to — if he'd rather not, add
`native/firebase/` to .gitignore and hand them over out of band, because the
build needs them.
